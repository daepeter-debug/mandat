# Portréty osobností – lokálna testovacia verzia

23 autentických fotografií, zdroje skontrolované 12. 9. 2026. Väčšina pochádza z oficiálnych webov strán; fotografie Branislava Gröhlinga a Mariana Kotlebu sú z Národnej rady SR. Kotlebov portrét je archívny, nie fotografia z roku 2026.

Presný pôvod každého súboru je v `lib/party-profiles.json` (`imageSource`). Odkaz **Foto** pri každom medailóne zobrazuje pôvodný obrazový súbor; **Zdroj profilu** dokladá údaje o osobe. Rok v URL fotografie neoznačuje aktuálnosť funkcie. Dátum kontroly sa vzťahuje na podklady, nie na dátum vzniku fotografie.

Fotografie sa načítavajú lokálne a až pri otvorení profilu. CSS zachováva proporcie a používa orez v portrétovom ráme. Uvedenie zdroja nie je udelením licencie.
