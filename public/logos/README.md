# Logá politických subjektov

Logá 13 subjektov nad 1 % v aktuálnom agregáte boli prevzaté z ich oficiálnych webov 12. 9. 2026. Presné adresy pôvodu a lokálne súbory sú v `../../lib/party-logos.json` a používateľ ich nájde v sekcii O dátach → Logá politických strán.

Originálne súbory ponechávame bez prekresľovania a prefarbovania. Zobrazenie používa object-fit: contain. PS, Demokrati a Aliancia poskytujú symbol samostatne; pri ostatných je zachovaná dostupná webová značka. Ide o identifikačné použitie; záznam pôvodu nepredstavuje udelenú licenciu ani prevod práv k značke.

Komponent Hemicycle načítava SVG podľa id subjektu. Historická koalícia má samostatné id election-2023-5 a nedostáva automaticky logo Hnutia Slovensko.
